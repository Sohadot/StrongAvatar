# SEO Architecture

SEO for StrongAvatar.com must be controlled, not expansive by default.

## SEO Doctrine

Search visibility should support reference authority around avatar strength, synthetic likeness governance, digital identity trust, and governed digital representation.

## Control Rules

- No indexable URL without registry approval.
- No duplicate-intent pages.
- No thin keyword capture.
- No generic avatar generator pages.
- No unsourced claims used for ranking.
- No page title or description outside the approved strategic purpose.

## Current Status

No public SEO surface is active in this phase.
