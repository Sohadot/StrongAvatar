# Sovereign Indexing System

Indexing is a privilege granted by governance, not a default consequence of file creation.

## Purpose

The sovereign indexing system keeps StrongAvatar.com from becoming a loose collection of pages. It ensures that every indexable URL is deliberate, registered, and aligned with the Avatar Strength Protocol.

## Indexing Rules

- No URL is indexable unless listed in `site/data/pages.json`.
- Each indexable URL must declare purpose, canonical intent, content type, and review status.
- Pages with insufficient sourcing, incomplete internal links, duplicate intent, or unclear buyer logic remain non-indexable.
- Drafts, tools under development, reports in preparation, and experimental content remain outside public indexing.

## Control Standard

The system should support controlled growth, clean removal, canonical discipline, redirect accountability, and acquisition diligence.
