# Sovereign Indexing System

Indexing is a privilege granted by governance, not a default consequence of file creation.

## Purpose

The sovereign indexing system prevents StrongAvatar.com from becoming a loose collection of pages, keyword targets, or generated SEO inventory. It ensures every indexable URL is deliberate, registered, useful, and aligned with the Avatar Strength Protocol.

## Core Rule

No page is indexable by default. Indexing requires registry approval.

Every indexable page must have:

- Strategic purpose.
- SEO cluster.
- Buyer logic role.
- Internal links.
- Canonical URL.
- Title.
- Description.
- Source status.
- Quality status.
- Publication status.

## Indexing Prohibitions

- No keyword-only pages.
- No orphan pages.
- No duplicate intent pages.
- No thin glossary pages.
- No mass SEO expansion.
- No public pages outside `site/data/pages.json`.
- No pages created only to capture search traffic.
- No pages that make the asset look like a generic AI avatar generator, low-quality avatar maker, affiliate shell, or generic AI blog.

## Sitemap Discipline

Sitemap generation must reflect only approved, published, indexable pages. Drafts, rejected pages, pending pages, private reports, unapproved tools, and experimental content must be excluded.

## Current Status

No public SEO surface is active. No sitemap generation is implemented. Public indexing remains disabled in Sprint 3.
