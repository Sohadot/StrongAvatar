# Sovereign Publishing Engine

The publishing engine is a future system for turning approved registries and governed content into a controlled public website.

This phase does not build the engine.

## Future Responsibilities

- Read approved data registries.
- Render only authorized content.
- Enforce canonical metadata.
- Preserve internal-link discipline.
- Exclude drafts and unapproved pages.
- Generate reports for review before deployment.

## Doctrine

Publishing must be deterministic and auditable. A file's existence must never imply public authorization.

## Current Status

No publishing engine is implemented. No templates, scripts, or public pages are active.
