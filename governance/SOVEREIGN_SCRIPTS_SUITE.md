# Sovereign Scripts Suite

The scripts suite is a future automation layer for validation, registry checks, reports, and controlled builds.

This phase does not implement scripts.

## Future Scope

- Registry validation.
- Quality-gate checks.
- Internal-link audits.
- Source registry audits.
- Redirect checks.
- SEO metadata checks.
- Pre-publish reports.

## Constraint

No script may publish, index, monetize, or generate public pages without explicit governance rules and review outputs.

## Current Status

`site/scripts/` is reserved. No executable automation is included in the foundation.
