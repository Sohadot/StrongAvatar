# UI Components

UI components are not implemented in this phase.

## Component Doctrine

Future components must serve governed explanation, source transparency, registry-driven publishing, and institutional readability.

## Candidate Future Components

- Protocol dimension card
- Source citation block
- Quality-gate status indicator
- Buyer segment summary
- Governance checklist
- Controlled navigation module
- Report summary panel

## Constraint

No component code, CSS, JavaScript, or placeholder UI should be created until the publishing architecture and content registries are approved.
